# GFL2 Bahasa Indonesia — Global

Paket teks bahasa Indonesia untuk **GFL2 Global PC Windows**, snapshot 14 Oktober 2026. Mod ini memakai slot bahasa **Thai/Thailand**.

[**Unduh LangPackageTableThthData.bytes**](https://raw.githubusercontent.com/RaizeiID/GFL2-Bahasa-Indonesia-Global-/refs/heads/main/LangPackageTableThthData.bytes)

## Cara memasang

1. Pilih bahasa **Thai/Thailand** pada pengaturan game, selesaikan unduhan bahasa jika diminta, lalu tutup game dan launcher.
2. Buka folder instalasi Global, lalu masuk ke:

   ```text
   GF2_Exilium_Data\LocalCache\Data\Table
   ```

3. Cadangkan file asli `LangPackageTableThthData.bytes` ke folder lain.
4. Unduh file di atas, salin ke folder `Table`, lalu pilih **Timpa/Replace**. Pertahankan nama filenya.
5. Jalankan game dengan bahasa **Thai/Thailand** untuk menampilkan terjemahan Indonesia.

Paket ini hanya berisi file teks utama. Label pilihan bahasa dan sebagian teks sistem dapat tetap memakai bahasa bawaan. Terjemahan mengikuti cakupan mod yang tersedia; bukan klaim seluruh konten sudah 100% Indonesia.

Gunakan pada baseline Global yang cocok. Update game dapat mengganti mod; periksa paket terbaru sebelum memasang ulang. Baseline English paket ini mempunyai SHA256:

```text
LangPackageTableEnusData.bytes
D1C7474EE93234C13CBF079A21CDE9637E83DC14971208A64C9F9EF365EFB8DC
```

Untuk mengembalikan bahasa bawaan, tutup game lalu pulihkan file backup dari versi game yang sama.
